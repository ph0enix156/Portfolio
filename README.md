# Pushkar Gangurde - Portfolio

Portfolio of Pushkar Gangurde — Computer Science Engineering student at MIT-WPU Pune building practical AI, computer vision, and full-stack software systems.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```
2. Run the dev server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.
